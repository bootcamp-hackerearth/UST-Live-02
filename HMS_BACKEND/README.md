# Hospital Management System - Sprint 1 Backend
 
This repository contains the backend services for Sprint 1 of POD 1's Hospital Management System (HMS). It provides the APIs and business logic required to manage employee accounts and authentication within the system.
 
## Features
 
- Employee Self-Registration
- Employee Login and Authentication
- Employee Profile Viewing
 
## Technology Stack
 
- Node.js
- Express.js
- REST APIs
 
## Sprint 1 Scope
 
The primary objective of this sprint is to establish the employee onboarding and access management workflow. Employees can create their accounts, securely log in to the system, and view their profile information. These functionalities serve as the foundation for subsequent HMS modules and enhancements.
