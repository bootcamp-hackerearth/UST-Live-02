# 🏥 Hospital Management System - Mobile

## 📖 Overview

React Native Patient Application developed using Expo.

---

## 🚀 Technology Stack

- React Native
- Expo
- TypeScript
- React Navigation
- Axios
- React Query

---

## ✨ Features

- Login
- Dashboard
- Profile
- Edit Profile
- Book Appointment
- Appointment List
- Appointment Details
- Health Records

---

## 📂 Project Structure

src/
├── screens
├── navigation
├── services
├── components
└── utils

---

## ⚙️ Installation

```bash
npm install

npx expo start
```

---

## 📱 Android

```bash
npx expo run:android
```

---

## 🍎 iOS

```bash
npx expo run:ios
```

---

## 🚀 Production Build

Using Expo Application Services (EAS)

```bash
eas build --platform android
```
