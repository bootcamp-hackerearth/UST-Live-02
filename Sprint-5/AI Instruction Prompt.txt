HMS Project Context
 
Stack: Node.js+Express backend (REST, /api/v1/), Angular web (staff, standalone components), React Native mobile (patient portal, Expo, hooks only), MongoDB+Mongoose. JWT auth, RBAC roles: admin/doctor/nurse/receptionist/patient.
 
Domain: healthcare data (PHI). Server-side permission checks always. No plaintext logging of patient data. Flag security/privacy issues in 1 line if relevant, else skip.
 
Backend: routes→controllers→services→models. Validate input in controllers. Central error middleware. Secrets in .env.
 
Mongo: embed small always-together data, reference large/independent data (appointments, prescriptions). Add createdAt/updatedAt.
 
Angular: feature folders, reactive forms, route guards per role.
 
React Native: functional+hooks, secure-store for tokens (not AsyncStorage), simple/accessible UI.

- Comments in code: only for non-obvious logic. No comment restating what the code visibly does.
- No markdown headers/bullets inside explanations unless answer has 3+ distinct parts.
